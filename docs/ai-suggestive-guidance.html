AI Suggestive Guidance

Patterns for AI-driven suggestions, nudges, and progressive disclosure that guide users without overwhelming them.

Guidance Patterns

AI suggestive guidance uses four core pattern types, each calibrated to a different level of intrusiveness. The right pattern depends on the user's current activity, the urgency of the suggestion, and how much context is needed for the user to act.

Pattern Use When Intrusiveness Level
Inline Suggestion User is actively editing Low
Suggestion Card User needs options Medium
Nudge User might benefit from action Medium
Progressive Disclosure Complex decision needed Low

Inline suggestions appear directly within the user's workflow, such as ghost text in an input field or an autocomplete recommendation. They should be visually subtle, easy to accept with a single keystroke, and never block the user's current action. Dismiss on any other input.

Suggestion Cards

[Insert suggestion card layout: card with title, description, accept/dismiss actions]

Suggestion cards present a structured recommendation with a title, brief description, and clear accept/dismiss actions. Each card should convey the suggestion's value in one or two lines. Cards can appear in a dedicated suggestions panel, inline within a list, or as a floating overlay near the relevant context.

Nudge & Tooltip Patterns

Nudges proactively surface AI insights or recommended actions, while tooltips provide on-demand explanations. Use nudges when the user may not be aware of an opportunity; use tooltips when the user is exploring and needs clarification. Nudges should be dismissible and respect frequency caps to avoid fatigue.

Progressive Disclosure

Progressive disclosure reveals AI-generated information in layers, starting with a concise summary and allowing users to drill into increasing levels of detail on demand. This pattern prevents information overload while keeping full transparency accessible.

Disclosure Levels

Level Content Shown Trigger
Summary Headline + confidence Default
Detail Explanation + data Click "Show more"
Full Raw data + audit Click "Full details"

Dismissal & Persistence

Suggestions must respect user preferences around dismissal. Overly persistent suggestions erode trust, while suggestions that disappear too quickly may be missed. Follow these rules to balance visibility with respect for the user's attention.

Behavior Rule
Single dismiss Hide for current session
Permanent dismiss Hide after 3 dismissals of same type
Re-surface Show again if context changes significantly
Snooze Allow user to set "remind me later"
