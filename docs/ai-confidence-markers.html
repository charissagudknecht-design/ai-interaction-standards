AI Confidence Markers

Visual and interactive patterns for communicating AI confidence levels, enabling user override, and maintaining audit trails.

Confidence Scale

The confidence scale provides a standardized way to communicate how certain the AI is about a given prediction, recommendation, or action. Each level maps to a specific color, label, and icon to ensure consistent visual communication across all AI-powered features.

Level Range Color Label Icon
High 90–100% Green High confidence Checkmark
Medium 70–89% Amber Moderate confidence Info
Low 50–69% Orange Low confidence Warning
Very Low <50% Red Needs review Alert

User Override Patterns

Accept

The user confirms the AI suggestion as-is. The system applies the value and logs the acceptance in the audit trail. High-confidence suggestions may be auto-accepted with an undo option.

Modify

The user edits the AI suggestion before applying it. The system preserves both the original AI value and the user-modified value in the audit trail for traceability.

Reject

The user dismisses the AI suggestion entirely and provides their own input. The system logs the rejection reason when available and uses this feedback to improve future suggestions.

Audit Trail

Every AI-driven decision should be logged with sufficient detail to support review, compliance, and model improvement. The audit trail captures the full lifecycle of an AI suggestion from generation through user action.
