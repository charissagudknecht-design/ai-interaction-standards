Visual Language

Color palettes, gradients, typography, and iconography that define Glow's visual identity. Includes exportable design tokens for the Ruby Berry theme.

AI Color Palette

AI elements use Ruby Berry as the primary accent, visually distinct from the Blue CTA colors used for standard actions. Confidence indicators reuse the design system's semantic Green, Yellow and Orange families.
