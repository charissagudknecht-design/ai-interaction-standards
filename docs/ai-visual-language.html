Confidence Colors

Confidence indicators reuse the design system's semantic Green, Yellow and Orange families. Each has a 4-step ramp: icons and text, dark accents, light accents and backgrounds. Orange is reserved for low confidence and errors. Dark accents pass AA only for large text and icons, so use the icons and text step for body copy.
