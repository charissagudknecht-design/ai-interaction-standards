AI Visual Specs

Color, typography, iconography, and layout specifications for AI-generated and AI-assisted interface elements. These specs extend the design system's existing token system with AI-specific additions.

AI Color Palette

AI elements use the design system's Lavender family as the primary AI accent — visually distinct from the Blue CTA colors used for standard actions. This separation helps users immediately recognize AI-involved content. Confidence indicators reuse the design system's semantic Green/Yellow/Red families.

Design Rationale

Element Color Why
User bubble --bg-cta-blue (#1a78c1) Consistent with the design system's primary action color — the user is initiating
AI bubble background --ai-surface (#eff0fd) Lavender differentiates AI from user; softer than blue to feel supportive, not assertive
AI bubble left border --ai-primary (#505382) 3px left accent clearly marks AI origin; same pattern used across all AI containers
Chat header --ai-primary (#505382) Signals "this is an AI surface" immediately on entry
"AI Generated" label --ai-primary (#505382) Every AI response must carry attribution — transparency principle
Conversation background --bg-default (#f8f9fc) Neutral background from the design system; keeps focus on message content

AI Typography

AI text uses the design system's standard Lato font family — not a different typeface. AI content should feel integrated, not foreign. The distinction comes from color (Lavender accents) and attribution badges, not typography changes.

Style Token Size Weight Usage
AI Response Heading --font-size-body-large 16px Semibold (600) Section titles within AI responses
AI Response Body --font-size-body-medium 14px Regular (400) Main AI response text, chat messages
AI Attribution --font-size-footnote-small 10px Semibold (600) "AI Generated" labels, uppercase with letter-spacing
AI Caption --font-size-footnote-medium 12px Regular (400) Confidence scores, timestamps, metadata
AI Prompt Input --font-size-body-medium 14px Regular (400) User input in prompt/chat fields
AI Code/Data Consolas, monospace 13px Regular (400) Inline data values, formulas, API references in responses

AI Iconography

AI icons use the product's existing icon set where possible. Where new icons are needed, they follow the design system's 24px grid, 2px stroke weight, and rounded line-cap conventions.

Icon Name Usage Status
✨ Sparkle / Star Default AI indicator — used in badges, chat headers, and attribution labels Primary — use this by default
⚡ Lightning AI-powered quick actions, instant suggestions Available in the icon set
ℹ Info Circle "Why this suggestion?" expandable explanations Available in the icon set
Checkmark High confidence indicator, accepted suggestion Available in the icon set
⚠ Warning Triangle Low confidence indicator, needs review Available in the icon set
↻ Refresh / Retry Regenerate AI response, retry on error Available in the icon set

Rule: The Sparkle icon is the universal AI marker. Every AI-generated surface must include it at least once — either in the header, the attribution badge, or both. Do not use brain, robot, or humanoid icons (see Anti-Patterns: Anthropomorphization).

AI Badge & Label Styles

Every piece of AI content must carry an attribution badge. Three tiers exist based on AI involvement level.

AI Generated AI Suggested AI Assisted
Badge Background Text Color When to Use
AI Generated --ai-surface (#eff0fd) --ai-primary (#505382) Content entirely produced by AI with no human edits. Chat responses, auto-generated reports.
AI Suggested --bg-blue (#e8f3fc) --text-blue (#1a78c1) Recommendations the user can accept, modify, or dismiss. Scheduling suggestions, smart replies.
AI Assisted --bg-cool-gray (#edeff5) --text-secondary (#435773) Content where AI contributed but a human authored or substantially edited. Drafts, auto-filled fields.

Placement rules: Badges appear above or inline with the AI content they describe. In chat, use the inline label format (smaller, uppercase). In cards and reports, use the pill badge format. Never hide the badge behind a hover or expandable section.

Dark Mode Considerations

AI tokens map to dark mode via the design system's [data-theme='dark'] selector. Colors shift to preserve meaning while maintaining contrast on dark surfaces. Surface colors become elevated rather than simply inverted.

Token Light Mode Dark Mode Notes
--ai-primary #505382 #a4a4d9 Lighten for contrast on dark backgrounds
--ai-surface #eff0fd #2a2b3d Elevated dark surface with lavender tint
--ai-confidence-high #1e6421 #4ade80 Lighten green for dark backgrounds
--ai-confidence-medium #9c7506 #fbbf24 Lighten yellow for dark backgrounds
--ai-confidence-low #e63447 #ff8a8a Follows the design system's dark mode red mapping
--ai-chat-user #1a78c1 #095997 Slightly darker blue on dark bg for depth

Contrast requirement: All text on AI surfaces must meet WCAG 2.1 AA (4.5:1 ratio for normal text, 3:1 for large text). Test each token pair in both themes before shipping.
