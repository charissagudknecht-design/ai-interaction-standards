Anti-Patterns

Documented mistakes to avoid when designing AI interactions — paired with the approved fix.

Overconfident AI

✗ Don't

Present AI outputs without confidence indicators, making users assume 100% accuracy.

✓ Do

Always show confidence level. Use the 3-tier scale. Never hide uncertainty.

Black Box Responses

✗ Don't

Provide answers without explaining reasoning or data sources.

✓ Do

Include "Why?" expandable sections. Link to source data. Show the reasoning chain.

Unrecoverable Actions

✗ Don't

Execute irreversible actions (sending emails, deleting records) without confirmation.

✓ Do

Always require explicit confirmation for destructive actions. Use "Review before sending" patterns.

Notification Overload

✗ Don't

Generate too many suggestions at once, overwhelming the user.

✓ Do

Use progressive disclosure. Show the top 1–3 suggestions, hide the rest behind "Show more."
